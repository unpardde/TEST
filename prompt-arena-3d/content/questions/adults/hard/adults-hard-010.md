# 供應商比較

## 情境
三家供應商報價已提供，但其中一家沒有列維護費。本次任務是「製作方案比較」，希望用一致口徑比較已知成本。教學模擬回覆：AI 依常見情境完成草稿，但沒有遵守「缺少維護費不能當成零元」。你沒有授權更改限制。

## 問題
若這項限制與「成品一次完成」衝突，應怎麼迭代？

## B
維持完整成品，把原限制改寫成建議，讓讀者自行決定是否需要採用。

## C
恢復原限制，指出哪些部分目前無法完成；保留其餘成果並提出最少必要問題。

## A
維持完整成品，增加一些專業說明，讓未遵守限制的做法顯得比較合理。

## D
維持完整成品，將衝突部分換成模糊措辭，不再明確說明是否符合限制。

## 解析
未經授權不能放寬限制。有效下一步是指出不可完成的部分並索取關鍵資訊，而不是掩飾衝突。

## 提示
先找出題目指定的目標，再比較每個選項真正改變了什麼。

## 解析 B
這個選項採用「維持完整成品，把原限制改寫成建議，讓讀者自行決定是否需要採用。」的方向，但與本題指定的目標或限制不同。未經授權不能放寬限制。有效下一步是指出不可完成的部分並索取關鍵資訊，而不是掩飾衝突。

## 解析 C
這個選項直接處理本題要求。未經授權不能放寬限制。有效下一步是指出不可完成的部分並索取關鍵資訊，而不是掩飾衝突。
