# 活動企劃

## 情境
部門有五萬元預算和四十名參與者，場地與餐點都要包含在預算內。本次任務是「擬定活動方案」，希望提出可進一步詢價的活動安排。教學模擬回覆：AI 產出「項目、估算費用、待確認事項表」，但為了讓文句好看，刪掉了會影響判斷的重要限制。

## 問題
哪個修正最能兼顧可讀性與正確性？

## D
維持目前簡潔版本，只在最後加上實際情形可能不同，不逐項補回條件。

## C
補回「總估算不超過五萬元，報價未取得須標假設」涉及的必要條件，再刪除重複修飾語；不犧牲判斷所需資訊。

## B
維持目前簡潔版本，把語氣改得較保守，讓讀者自行留意可能的例外。

## A
維持目前簡潔版本，把必要條件改成另一份文件，這份成品不再提及。

## 解析
可讀性不能靠刪掉改變適用結果的條件達成。可先保留必要資訊，再精簡贅詞。

## 提示
先找出題目指定的目標，再比較每個選項真正改變了什麼。

## 解析 C
這個選項直接處理本題要求。可讀性不能靠刪掉改變適用結果的條件達成。可先保留必要資訊，再精簡贅詞。
